## 1. 准备与可恢复升级

- 确认 ESP32-S2 mini / S2FNR2，4 MB flash、2 MB PSRAM，接线见根目录指南。
- 保留 v1.2.0 应用固件、当前网络配置和串口密码记录；需要备份配置时先做好备份。
- 下载 v1.3.0 的 `firmware.bin` 和 `SHA256SUMS.txt`，核对同名文件的 SHA-256。
- 保留配置的升级只上传应用；**不运行 uploadfs，不上传合成镜像到 Web OTA**。
  需要完整重新初始化时，先备份，再从 `0x0` 烧写合成镜像；它会覆盖旧配置。
- 保持稳定供电，USB 原生串口重新枚举后确认端口；115200，必要时置位 DTR / RTS。
- 保留串口烧写恢复路径。未实现应用启动健康检查与自动回滚；能启动不等于功能正常。

## 3. DNS 正确性、缓存与主备

下面的设备地址必须替换为实际地址。这是串行探针，不是固定 QPS 压力测试：

```bash
python 3.98/merged-adblock-epd/tools/dns_probe.py --server 192.168.1.50 --domain doubleclick.net --count 100
python 3.98/merged-adblock-epd/tools/dns_probe.py --server 192.168.1.50 --domain example.com --count 100
python 3.98/merged-adblock-epd/tools/dns_probe.py --server 192.168.1.50 --domain example.com --tcp --count 20
python 3.98/merged-adblock-epd/tools/dns_probe.py --server 192.168.1.50 --domain example.com --aaaa --count 20
```

|操作|期望|结果|
|---|---|---|
|A / AAAA 查询已拦截域名及子域名|返回 0.0.0.0 / ::；UDP 与 TCP 均拦截|待测|
|添加原本不在主表的 ads.example.com|自身和子域名拦截，不受主表 Bloom 门控|待测|
|主表缺失或加载失败时保留自定义规则|自定义规则仍拦截；仅主表过滤失效|待测|
|构建 --bloom-bits 1000000 的小表并上传|所有已输入域名都拦截，无 Bloom 假阴性|待测|
|重复标准 A / AAAA，无 EDNS|cacheHits 增长；TTL 递减，不超过原始 TTL|待测|
|TTL 到期、超过 16 项、变更规则 / 封禁 / 上游|重新查询上游，不返回过期缓存；新规则优先|待测|
|NXDOMAIN、EDNS / DNSSEC、TC 或带附加节|不缓存；不将正缓存套用到不同类型 / 标志|待测|
|主上游无响应、备用正常|约 2 s 后备用回应，dnsRetries 增加|待测|
|两上游均无响应|约两个超时窗口后 SERVFAIL，dnsTimeouts 增加|待测|
|伪造来源 / ID / 问题的上游应答（可控测试网络）|拒绝，dnsRejected 增加，不完成错误 pending|待测|

探针只验证头部、ID、RCODE 和延迟；检查地址 / TTL 需要 `dig`、`nslookup` 或抓包。
现代工具通常自动附 EDNS，TTL 缓存测试需显式关闭 EDNS（如 `dig +noedns`）。
主备上游默认 9.9.9.9 / 1.1.1.1，不要配置本机或会回送本设备的路由器。
TCP 客户端转发仍访问 UDP 上游，不实现上游 TCP 截断重试。

## 5. 更新失败保护与 HTTPS

|操作|期望|结果|
|---|---|---|
|未认证、缺 token 或错误 token 上传|START 阶段拒绝，不写入 / 激活，不重启|待测|
|OTA 上传合成镜像、其他芯片固件、截断 / 损坏 / 超大文件|报错，旧应用继续运行，无自动重启|待测|
|填写错误 SHA-256|拒绝激活，不重启|待测|
|正确同版 firmware.bin|长度 / 镜像验证成功，成功响应后重启|待测|
|上传规则的错误头、错误长度、写满空间或中途断开|清理临时文件，旧列表继续拦截|待测|
|后台下载时再次上传规则 / OTA|拒绝并发，不能覆盖同一个临时文件|待测|
|未配置 CA / 未 NTP 对时的 HTTPS|明确拒绝，不绕过证书验证|待测|
|正确 CA、错误 CA、主机名不匹配 / 过期证书|仅可信证书链与主机名匹配时成功|待测|
|慢 / 断流、chunked、Content-Length、跳转、gzip|前两种正常封帧可成功；截断 / 超时 / 跳转 / gzip 拒绝，旧表不变|待测|
