# Triage 标签

技能以五个标准的 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这张票                     |
| `needs-info`               | `needs-info`         | 等待报告者补充更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给无人值守的 agent         |
| `ready-for-human`          | `ready-for-human`    | 需要由人来实现                           |
| `wontfix`                  | `wontfix`            | 不予处理                                 |

当技能提到某个角色（例如「apply the AFK-ready triage label」），就使用上表中对应的标签字符串。

若要改用别的词汇，直接编辑右列即可。
