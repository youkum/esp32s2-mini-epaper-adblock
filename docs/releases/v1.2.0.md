# v1.2.0 — 刷新与黑名单更新优化，补全构建和部署说明

本版本让 BOOT 按键检测不再等待松开，面板忙时把手动刷新加入队列；仪表盘 Top 10
每帧只计算一次。黑名单上传和下载先校验临时文件再替换，修正短读、下载不完整和上传失败仍报成功的问题。
保留 64 行分带与 12,288 字节缓冲，不引入全帧缓冲。

平台固定为 `espressif32@6.12.0`（Arduino-ESP32 2.0.17 / S2 SDK 4.4.7）。
修正 Windows 烧写脚本路径和 PowerShell 5.1 编码；合成镜像缺少文件系统或产物超出容量时会报错。
更新部署、编译、开源引用和第三方声明，区分首次烧写与保留配置的应用升级。

## 下载与使用

|附件|用途|
|---|---|
|`firmware-merged.bin`|首次部署 / 重新初始化，从 `0x0` 烧写；含 bootloader、分区表、应用与 LittleFS，会覆盖配置|
|`firmware.bin`|已有设备的 Web OTA 应用升级；不要在 OTA 中上传合成镜像|
|`littlefs.bin`|文件系统分区镜像，偏移 `0x250000`；烧写会覆盖该分区全部配置|
|`blocklist.bin`|通过 Web 控制台只更新规则，保留其他配置|
|`esp32s2-flash-v1.2.0.zip`|bootloader、partition table、OTA 选择数据、应用与文件系统分区烧写组件|
|`esp32s2-debug-v1.2.0.zip`|`firmware.elf`、`firmware.map`、应用目标文件及构建配置，用于调试和重新链接参考|
|`release-docs-v1.2.0.zip`|部署指南、构建记录、署名、第三方声明及核对过的上游许可文本|
|`release-metadata.json` / `SHA256SUMS.txt`|源码提交、实际工具版本、产物大小与 SHA-256 校验和|

目标是 ESP32-S2 mini / 4 MB flash / 2 MB PSRAM 与 768×552 四色面板。
完整步骤见 [GUIDE.md](https://github.com/youkum/esp32s2-mini-epaper-adblock/blob/v1.2.0/GUIDE.md)。
