# v1.3.0：正确性与非阻塞状态机测试版

发布日期：2026-11-21（北京时间）。目标为 ESP32-S2 mini / S2FNR2，4 MB flash + 2 MB PSRAM。
本版标记为 **Pre-release，等待用户实机验收**；保留 v1.2.0 正式版为 Latest。

## 修复与优化

1. **排行榜**：修正计数增加后的上浮；固定 12 项 Space-Saving 支持新热点替换最小候选，
   保存完整域名。网页显示计数上界 / 误差，屏幕沿用上界，明确不是精确无限榜单。
2. **Bloom 与规则**：64 位中间计算与构建器一致，覆盖非 2 次幂参数；自定义规则不再
   被主列表 Bloom 或空主表跳过。构建器拒绝来源读取失败 / 空表 / 非法参数，原子输出。
3. **屏幕 / WiFi / 下载**：面板每次服务最多两条完整行，固定帧快照；WiFi 关联和重连
   不再等待主循环，连接成功重绑 DNS；远程 HTTP(S) 下载移到后台，主循环统一安装列表。
4. **面板恢复**：BUSY 阶段 45 s、单次整帧 120 s 限制，2 s 退避后最多再试两次，
   未观察到刷新 BUSY 明确报错。状态、行数、故障数和最大 loop 用时可从控制台查看。
5. **更新安全**：上传 START 阶段验证 Basic Auth + 128 bit CSRF，OTA 检查长度、芯片、
   ESP-IDF 镜像和可选 SHA-256，失败不重启；未启用未认证 ArduinoOTA。
   HTTPS 配置 PEM CA 和 NTP 对时，不跳过证书验证、不自动跳转；增加进度 / 错误 / 空间信息。
6. **DNS**：16 项 / 每项 512 字节的保守正响应 TTL 缓存；主备 IPv4 上游可配置。
   主上游 2 s 超时后使用备用，最终失败返回 SERVFAIL；严格校验应答来源、ID 与问题。

配置文件改为临时写入后替换，失败不假报保存成功；自定义规则按钮不再拼接动态 JS。
新增原生 C++ 回归、构建器失败保护测试、串行 DNS 实机探针和 GitHub Actions 构建检查。

## 已完成与未完成

编译、模拟算法 / GPIO、脚本测试、LittleFS 和合成镜像验证见[构建记录](../BUILD-VERIFICATION.md)。
发布前没有实机测试；2026-11-21 发布后已完成完整烧写、启动自检和两次屏幕刷新，
用户确认画面正常，见[实机记录](../HARDWARE-TEST-2026-11-21.md)。继续按
[验收清单](../HARDWARE-TEST-CHECKLIST.md)验证并发、BUSY、WiFi / DNS 连续性、TLS、
OTA、flash 掉电与长跑。发行附件保留发布时快照，最新实机结果以仓库文档为准。
以下边界没有消失：

后续密码持久化验证通过；软件复位后出现约 148 ms 的短 BUSY，面板恢复仍待排查，
不能把“帧完成”日志等同于实际刷新正常。

- 禁止全帧缓冲，仍使用原 64 行 / 12,288 字节分带及 bit-bang 字节时序。
- lwIP UDP 邮箱仍为 6，没有重新编译网络栈；不承诺瞬时突发不丢包。
- 一个分带绘图、flash 写入及同步 WebServer multipart 仍可能造成短暂停顿。
- TCP 客户端上游仍为 UDP；不实现完整递归、上游 TCP 截断重试、负缓存或 DNSSEC 验证。
- CADB 结构校验不验证表内排序 / Bloom 数据内容或数据来源真实性。
- 未实现启动健康验收、自动回滚、固件签名或防降级。
- **旧黑名单输入快照及 SimHei 点阵再分发依据仍待补**，详见第三方声明；发布动作不解决许可缺项。

## 下载与部署

- `firmware.bin`：已有设备 Web OTA / 应用烧写，保留配置；可填写同文件 SHA-256。
- `firmware-merged.bin`：从 0x0 烧写，用于首次部署 / 重新初始化，会覆盖配置。
- `littlefs.bin` / `blocklist.bin`：完整文件系统镜像 / 单独列表，前者覆盖整个文件系统。
- `esp32s2-flash-v1.3.0.zip`：分区烧写组件；`esp32s2-debug-v1.3.0.zip`：ELF / map / 应用目标文件。
- `release-docs-v1.3.0.zip`：部署与验收文档、主要上游条款材料。
- `release-metadata.json` / `SHA256SUMS.txt`：源码提交、实际工具链、校验和及验证范围。

请从同一个 tag 下载匹配附件。指南见仓库根 GUIDE.md；Web OTA 不接收合成镜像，
已有设备升级通常不要 uploadfs。遇到故障保留串口恢复方式，不把测试版直接扩展到全网。
